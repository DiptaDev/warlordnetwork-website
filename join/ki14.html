How to Join on Minecraft Java

1. Open Minecraft Launcher and select any version (server support 1.8 - 1.21.5)
2. Click "Multiplayer" → "Add Server"
3. Enter the Server Name: WarLord Network (You can set it what ever your want)
4. Enter the Server Address: warlordnetwork.mineplay.tech
5. Click "Done", then select the server and click "Join Server"

How to Join on Minecraft Bedrock

1. Open Minecraft on your Bedrock device (Mobile, Console, or Windows 10/11)
2. Go to "Play" → "Servers" → Scroll down and click "Add Server"
3. Enter the Server Name: WarLord Network (You can set it what ever your want)
4. Enter the Server Address: warlordnetwork.mineplay.tech
5. Enter the Port: 31972
6. Click "Save", then select the server and click "Join"
NOTE: Some time the port will change and we will announce it on discord
